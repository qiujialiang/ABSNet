# ABSNet

This repository provides the trained ABSNet checkpoints for lightweight hyperspectral image classification.

The training code is based on [ACB](https://github.com/zhulongyu1234/ACB). The ABSNet model code is coming soon.

Trained checkpoints are provided in the `results/` folder:

- `results/Houston/ARSNet/best_model_epoch.pt`
- `results/Hyrank/ARSNet/best_model_epoch.pt`
- `results/Pavia/ARSNet/best_model_epoch.pt`
